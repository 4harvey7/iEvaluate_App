HOW TO READ THIS DOCUMENT
--------------------------------------------------------------------------------
* Text in "double quotes" appears on screen exactly as written. Match it
  character for character. {name}, {email} and similar stand for values.
* Names in [square brackets] are database tables or edge functions to check
  when a step needs back-end verification.
* Each step has its own expected result, so a failed case identifies WHICH
  step failed.
* "Revision" says whether the case is unchanged, updated, removed or new
  in this edition. "Account Needed" lists the sign-ins the case uses.
* "Actual Result" is blank where the case has not been run on this build.
  Results from older builds are kept in Comments, marked "Old run".
!! DESTRUCTIVE-ACTION WARNING !!

  registrations, switch the active term for the whole system, and change
  what is printed on official reports. Cases marked [LIVE DATA] change real
  records. Cases marked [DESTRUCTIVE] change or remove shared records in a
  way other users will notice. Run both on staging, or on throwaway accounts
  you are willing to lose, and never during a live evaluation period.

DEF-02  Word cloud clips words at the panel edge
        SEVERITY: MEDIUM      STATUS: FIXED 31/08/2026, PENDING RE-TEST
--------------------------------------------------------------------------------
  In "AI Word Cloud" the rotated term "Fair grading" ran past the right edge of
  the dark panel and was cut off mid-word, so it could not be read.

  between refreshes, making this intermittent rather than tied to one term.

  ROOT CAUSE, CONFIRMED IN CODE
  Nothing bounded a word to the panel. The words sit in a Wrap inside a
  fixed-padding Container, and each word was a bare Text with no width
  constraint, so a word wider than the panel simply overflowed it. Rotated

      inner width is known at layout time.

      rendered slightly smaller instead of running off the edge. scaleDown only
      ever reduces, so no word grows beyond the size its count earned it.
    - The same bound sits inside RotatedBox, where the swapped constraints make
      it cap the rotated word's height. Both extents are now bounded, so
      clipping is impossible by construction rather than by luck of the shuffle.

   verdict; the rest say NOT EXECUTED and why.
