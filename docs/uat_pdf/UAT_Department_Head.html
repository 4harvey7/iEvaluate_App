WHAT THIS ROLE DOES
  The Department Head reviews the faculty in their OWN department, spots who is
  struggling, and takes formal action through an intervention report. Two
  properties matter more than anything cosmetic:
    1. SCOPE  - a head sees only their own department, never the whole college.
    2. EFFECT - an intervention they raise reaches the instructor, and an
                instructor cannot dismiss it.
  This role can also deactivate an instructor's account, so that path is tested
  explicitly.
--------------------------------------------------------------------------------
HOW TO READ THIS DOCUMENT
--------------------------------------------------------------------------------
* Text in "double quotes" appears on screen exactly as written.
* Names in [square brackets] are database tables or services to check when a
  step needs back-end verification.
* Each step has its own expected result, so a failed case identifies WHICH
  step failed.
* "Actual Result" is blank where the case has not been run.
* "Revision" says whether a case is unchanged, updated or new for the build
  above. "Account Needed" names the account(s) the case needs.
!! WARNING !!
  Cases marked [LIVE DATA] create real intervention records against real
  instructors, or deactivate a real account. Run them on staging, or on a
  throwaway instructor account, and never during a live evaluation period.
  Cases marked [DESTRUCTIVE] change the shared database in a way that needs
  an SAO admin to undo. TC-D08 (deactivating an instructor) is the
  highest-impact action in this module.

Revision

updated - renamed labels, no forms panel, packed word cloud
